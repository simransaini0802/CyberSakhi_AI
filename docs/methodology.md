# Methodology

1. Gather a documented and appropriately licensed labelled dataset.
2. Inspect labels and class balance.
3. Normalize text and define a reproducible train/test split.
4. Build a TF-IDF + baseline classifier.
5. Evaluate using precision, recall, F1-score, and confusion matrix.
6. Compare against the transparent heuristic baseline.
7. Document limitations, false positives, false negatives, and privacy choices.
