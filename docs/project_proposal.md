# Project Proposal: CyberSakhi AI

## Title
An Explainable NLP-Based Scam Message Detection and Analysis System

## Problem statement
People receive unsolicited messages that may use urgency, unexpected rewards, requests for sensitive information, or suspicious links. This project explores how transparent NLP-based indicators can help users review such messages.

## Objectives
- Build a web-based message analysis interface.
- Implement text normalization and pattern analysis.
- Highlight possible warning indicators and safer next steps.
- Maintain local scan history and aggregate statistics.
- Train and evaluate a labelled-data classifier in a future phase.

## Scope and limitations
The starter application uses heuristic rules and is not a validated security product. It cannot guarantee detection, establish that a message is safe, or verify URL reputation.
