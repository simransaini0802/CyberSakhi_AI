ABOUT THE PROJECT

Technology with a human touch.

CyberSakhi AI is an educational MCA project exploring NLP techniques for safer digital communication.

Project objectives

  • Explore text cleaning and tokenization.
  • Identify common suspicious message patterns.
  • Build a Flask interface with scan history and a dashboard.
  • Prepare a labelled dataset and evaluate a future ML classifier responsibly.
  • Explain system indicators clearly rather than presenting an unexplained score.

Current implementation

The starter version uses transparent regular-expression rules for selected patterns and URLs. It does not yet include a trained machine-learning model, a live threat-intelligence service, or verified URL reputation checks.

Suggested next phase

Use a documented, appropriately licensed dataset to train a TF-IDF classifier. Evaluate it with precision, recall, F1-score, and a confusion matrix on held-out data. Keep the heuristic baseline separate from the trained model.
